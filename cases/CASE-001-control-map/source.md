## §2 · 抽幀 OCR 原文

### 6–12s 幀 · 全片骨架（三張圖 × 三個問題）

| 控制圖 | 對應問題（畫面原文） |
|---|---|
| 深度圖 Depth map | 一：動作復刻 |
| 法線圖 Normal map | 二：人物真實性 |
| 線稿圖／動態輪廓圖 | 三：產品一致性 |

### 38s 幀 · ★ Codex 的回應（逐字，本案最有價值的一段 OCR）

> 「我會把這張圖做成可拖拽觀察的 2.5D 三維場景：以灰度推斷前後深度，生成位移網格，
> 並加上**受限的軌道相機**，避免側移過大時暴露單張圖無法還原的區域。」

**⚠️ 這句話同時是技巧一的邊界聲明。** 作者把它當成成功的證據播出來，
而它其實是失敗條件的說明書——**「受限」不是保守設定，是物理事實。**

### 88s 幀 · 技巧三的提示詞（逐字）

> 「提取這兩個圖的線稿，背景為白色」

### 14–16s 幀 · 深度九宮格分鏡法（作者教程頁截圖，⚠️ OCR 品質差）

> 直接把普通九宮格交給視頻模型，分鏡圖中的顏色、紋理、錯誤五官和畫面噪點也可能影響成片。
> 處理方式是先把九宮格轉換成深度圖，只保留人物輪廓、動作姿態、鏡頭構圖和空間層次，
> 再分別提供人物、場景和道具參考圖。

**職責分工表（OCR 重建）：**

| 參考素材 | 只負責 |
|---|---|
| 深度九宮格 | 時間序、動作過程、機位和構圖 |
| 人物面部圖 | 五官、髮型、眼睛和配飾 |
| 人物全身圖 | 身材比例、服裝和鞋子 |
| 場景圖 | 空間結構、環境材質和燈光 |
| 道具圖 | 核心道具的造型與顏色 |
| 文字提示詞 | 解釋劇情、圖片職責和**禁止事項** |

### 16s 幀 · 深度圖提取提示詞（⚠️ OCR 嚴重失真，以下為可辨讀骨架）

```
① 灰階定義：近處為白色、遠處為黑色，中間灰調連續過渡
② 必須保持：比例、構圖、鏡頭角度、主體位置與角度、人物、前後遮擋關係
③ 禁止事項：重新設計構圖、移動／增加／刪除人物與物體、改變服裝、
             補充新細節、改變畫面顏色／紋理／文字／光影風格
④ 輸出規格：只輸出一張與原圖尺寸一致的灰度深度圖，
             不加邊框、說明文字、色階圖例或裝飾
```

**🔴 ①的黑白方向 OCR 兩處互相矛盾**（一處讀為近白遠黑、一處讀為近黑遠白）。
**這是會直接決定成敗的一個位元，使用前必須實測確認，不得照抄**（缺口 CM-G2）。
