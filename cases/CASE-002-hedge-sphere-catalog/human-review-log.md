# 人工重讀時推翻分類器的紀錄

**分類器：** `scripts/triage_reels.py`（規則式）｜**錯誤率：** 仍為 `UNMEASURED`
**用途：** 每一筆都是分類器判 `WORTH_SKILL`、但人讀完後推翻的案例。

> **這份檔案存在的理由：** `classifier_error_rate` 是 `UNMEASURED`，
> 而「UNMEASURED」不該變成「所以不用管」。
> **每抓到一次誤判就記一次**，累積到有 ground truth 為止。
> 累積夠了才算得出錯誤率——在那之前，這裡的筆數是我們對它唯一的了解。

## FP-1 · `DZ40OG8GDqF` — 業配廣告被判為技巧片

| | |
|---|---|
| 分類器判定 | `WORTH_SKILL` |
| 人工判定 | **`SPONSORED` — 不做 skill** |
| 內容 | 推銷某個「AI 工作流社群／模板市集」網站，通篇是產品介紹與變現話術 |
| 為什麼騙過分類器 | 廣告文案本身就充滿「首先」「第二步」「上傳」「選擇」「調整參數」——**動作訊號全中，但那些動作是在描述那個網站的操作介面，不是在教一個技巧** |

**★ 這是分類器的第一個確認誤判，而它暴露的是規則的根本限制：**
規則數得出「有沒有動作句」，數不出「這些動作屬於誰」。
產品導覽與技巧教學在詞彙層面幾乎無法區分。

**要不要修規則？暫時不修。** 加「業配偵測」規則的風險是把真的技巧片也擋掉，
而目前 n=1。**先累積案例，不要用一個樣本去改一把尺。**
